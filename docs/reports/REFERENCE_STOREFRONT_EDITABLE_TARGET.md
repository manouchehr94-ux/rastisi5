# RastiSi — مرجع صفحه فروشگاهی رنگی و قابل ویرایش

## مرجع بصری
مرجع محصول، اسکرین‌شات فروشگاه لوازم‌تحریر رنگی تأییدشده توسط مالک محصول در 2026-08-17 است.

## اصل غیرقابل مذاکره
Preset باید بتواند صفحه‌ای بسیار نزدیک به مرجع بسازد، اما پس از اعمال، هیچ بخش، رنگ، پس‌زمینه، ترتیب یا ترکیبِ آن نباید به کد مخصوص همان فروشگاه قفل باشد.

## اجزای مرجع
- نوار اعلان و Header جستجو-محور
- Hero + پیشنهاد جانبی
- ردیف دسته‌بندی تصویری
- ردیف اعتماد/مزایا
- بنرهای تبلیغاتی چندتایی
- چند Product Rail رنگی با الگوی ظریف
- بنرهای دوتایی و ترکیب‌های چندستونه
- مجموعه‌های محصول متنوع
- Footer کامل

## پس‌زمینه
پس‌زمینه یک قابلیت داده‌ای است:
- پس‌زمینه هر Content Block مستقل قابل تغییر است.
- Container چندخانه‌ای نیز می‌تواند پس‌زمینه مستقل داشته باشد.
- حالت‌ها: قالب، رنگ ساده، رنگ+الگو، و برای Sectionها تصویر MediaAsset امن.
- رنگ‌های مرجع صرفاً Quick Preset هستند، نه محدودیت.

## معیار پذیرش
صفحه مرجع باید با قابلیت‌های عمومی Builder و Preset داده‌محور قابل بازسازی باشد؛ بدون HTML/CSS/Python اختصاصی برای slug/id یک فروشگاه.

# Storefront Builder V2 — Reuse Matrix

**Phase:** Architecture revision (v2). Classification only — no implementation in this or the prior commit.

**Revision note:** this matrix was produced during the initial audit checkpoint (commit `6eac71b`) and is now revised to reflect nine locked owner decisions (see `STOREFRONT_BUILDER_V2_IMPLEMENTATION_PLAN.md` for the full decision record). Rows affected by an owner decision are marked **`[REVISED]`**. Unmarked rows are unchanged factual findings from the original audit and are not re-litigated here.

Classifications used (per the task's Step 19 requirement):
`REUSE_AS_IS` · `EXTEND` · `REFACTOR` · `LEGACY_KEEP` · `REPLACE` · `REMOVE_LATER`

**Evidence-language correction (owner-mandated):** the original audit used `TESTED` to mean "a test file exists and its assertions were read, not executed." That term is retired going forward in favor of the clearer `SOURCE_WITH_TEST_COVERAGE`. Rows below that previously said `SOURCE_ONLY / TESTED` now say `SOURCE_ONLY / SOURCE_WITH_TEST_COVERAGE` — no new verification occurred; this is a wording clarification only. No item below reached `RUNTIME_VERIFIED` or `BROWSER_VERIFIED` — no Django runtime was available in either session that produced this document.

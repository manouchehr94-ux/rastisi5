# Approved Storefront Visual Reference — V5

RastiSi Universal Storefront preset.

Status: APPROVED VISUAL REFERENCE

Purpose:
- visual fidelity reference
- block extraction reference
- responsive/layout reference
- acceptance testing against the Universal Storefront Engine

Important:
- this directory is NOT the production storefront renderer
- production RastiSi must not depend on this directory at runtime
- no Beraito-specific renderer, store conditional, or template family may be
  created from this reference
- the final implementation must reproduce this design through the Universal
  Block Engine and configuration/preset data

# راهنمای بسته سبک پنج قالب RastiSi

این بسته جایگزین کم‌حجم بسته ۷۶ مگابایتی است و برای Session جدید Claude Code ساخته شده است.

## محتویات

- `index.html`: گالری و مسیر ورود به پنج قالب؛
- پوشه `pages/`: ده صفحه مستقل، شامل پنج صفحه اصلی و پنج صفحه محصول؛
- `shared.css`: نسبت‌ها، چیدمان، رنگ‌ها، فاصله‌ها، حالت موبایل و تفاوت واقعی پنج خانواده؛
- `app.js`: DOM هر خانواده، محتوای نمونه، مشخصات دیداری و توضیحات قابل نمایش داخل هر صفحه؛
- `IMPLEMENTATION_SPEC_FA.md`: قرارداد دقیق Template/Section/Component/Mobile/Product؛
- `CLAUDE_CODE_MASTER_PROMPT_LIGHTWEIGHT.md`: دستور اصلی Claude Code.

## روش مشاهده

فایل `index.html` را در مرورگر باز کنید. از گالری وارد صفحه اصلی یا محصول هر قالب شوید. در نوار بالای هر صفحه، دکمه «مشخصات دقیق این صفحه» توضیحات همان خانواده را باز می‌کند.

## معنی ایموجی‌ها

ایموجی‌ها بخشی از طراحی نهایی نیستند. آن‌ها فقط جای کادر رسانه را با کمترین حجم نشان می‌دهند:

- نسبت و اندازه کادر مهم است؛
- جایگاه آن در Layout مهم است؛
- رفتار Cover/Contain و تصویر دوم مهم است؛
- خود ایموجی، رنگ یا محصول نوشته‌شده داخل آن مهم نیست.

Claude Code باید در RastiSi4 این کادرها را به Media picker، محصول واقعی، Collection واقعی و داده‌های Builder متصل کند.

## ترتیب ارسال به Claude Code

فقط ZIP همین پوشه را در Session متصل به Repository اصلی `RastiSi4` آپلود کنید. سپس متن داخل `CLAUDE_CODE_MASTER_PROMPT_LIGHTWEIGHT.md` را به‌عنوان دستور اصلی بدهید.

پنج ZIP اصلی و بسته سنگین لازم نیستند. اگر بعداً فقط برای یک جزئیات خاص اختلاف دیداری ایجاد شد، می‌توان همان یک Screenshot کوچک را جداگانه ارسال کرد.

## محدودیت صادقانه

این بسته ساختار، نسبت‌ها، سلسله‌مراتب، رنگ پایه، چگالی، نوع کارت، رفتار موبایل و معماری صفحه محصول را بسیار دقیق منتقل می‌کند؛ اما بدون تصاویر اصلی نمی‌تواند Crop، نور، بافت و Art direction عکس‌های مرجع را پیکسل‌به‌پیکسل منتقل کند. این کمبود باید بعداً با تصاویر واقعی هر Merchant پر شود و نباید باعث ساخت یک قالب عمومی و مشابه برای هر پنج خانواده شود.

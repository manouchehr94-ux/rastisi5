## نتیجه‌گیری

هر سه Family در پیاده‌سازیِ فعلی صرفاً یک «Wrapperِ هندسیِ ابداعی» (Capsule/
لبه‌تیز/Arched) رویِ همان بدنه‌ی مشترکِ اسلایدر/گرید بوده‌اند — نه واقعاً
ساختارِ صفحه‌ی مرجع. اصلاحِ زیر بر همین سند انجام می‌شود؛ هرجا ساختارِ مرجع با
بدنه‌ی مشترکِ Builder فرق دارد (مثلِ نبودِ Hero اسلایدری در artisan_editorial،
یا نوارِ موبایلِ modern_fashion)، Composition/Partialِ کاملاً مجزا نوشته
می‌شود، نه Override رویِ همان بدنه.

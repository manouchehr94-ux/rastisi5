# Site Targets 5 — Visual Reference Kit

این پوشه شامل 5 فولدر مرجع تصویری است که کاربر از 5 سایت واقعی جمعآوری کرده است.

محتوا:
- برای هر سایت: اسکرینشات صفحه اصلی (Home)
- اسکرینشات صفحه لیست محصولات (Listing / Collection)
- اسکرینشات صفحه جزئیات محصول (PDP)

هدف:
- این تصاویر مرجع طراحی بصری برای بازطراحی 5 قالب از 8 Ready Template فعلی هستند.
- این تصاویر برای الهام گرفتن از layout, spacing, hierarchy, card design, header, footer, PDP structure و visual rhythm استفاده میشوند.
- هدف نزدیک شدن حداکثری به حس و ساختار این سایتها است نه کپی پیکسلبهپیکسل.

قانون اجرایی:
- Claude باید ابتدا این 5 فولدر را audit و دستهبندی کند.
- سپس از بین 8 قالب موجود بهترین 5 قالب را برای Match با این 5 مرجع انتخاب کند.
- فقط همان 5 قالب در این فاز overhaul شوند.
- 3 قالب دیگر فعلا برای فاز بعدی untouched بمانند.

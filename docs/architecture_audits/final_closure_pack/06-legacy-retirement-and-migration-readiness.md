Zero Ready-recipe references does not establish that a section is unused. **RECOMMENDATION:** **0 items are classified SAFE TO DELETE NOW**. Source alone does not supply deployed-data migration, caller retirement or rollback evidence.

This is a retirement-readiness record, not authorization to migrate or delete. “DEPRECATE” means a candidate for eventual removal after prerequisites, not remove now. **KEEP** includes intentional immutable history/recipe copies. **CANNOT DETERMINE** is used for actual usage/recoverability questions that source cannot resolve.

Earliest phase labels are evidence gates, not code tasks: **G0**=product/authority decisions; **G1**=safe replacement boundary proven; **G2**=data migration and equivalent render/recovery proof; **G3**=traffic/adoption and rollback observation complete. None is claimed complete.

## Preservation constraints

**RECOMMENDATION:** Retirement must not rewrite catalog pricing, stock, tax, cart/order calculations, authentication, tenant resolution or publication eligibility. New appearance contracts should consume the current domain services. Preserve supported old inputs until transformed data, readers and rollback are proven. A code adapter and an immutable snapshot are not harmful duplication merely because they represent related concepts twice.

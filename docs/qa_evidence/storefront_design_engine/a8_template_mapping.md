## Mapping guardrails

* Each row names all ten Store Appearance families. Future Tasks 2–4 must resolve
  these semantic keys through trusted registries and may not persist prototype IDs.
* The eight historical keys/versions are retained exactly above; material A8
  revisions must be registered as later versions without removing those versions.
* No palette token is raw prototype CSS; palette labels are proposed registry slugs
  that must be selected from the typed palette catalog or replaced by a registered
  equivalent during Task 4.
